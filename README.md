
# Sistem Pemesanan Tiket Bus

## Deskripsi
Proyek ini merupakan aplikasi Sistem Pemesanan Tiket Bus yang dikembangkan menggunakan bahasa pemrograman Python dengan konsep Object-Oriented Programming (OOP).

Aplikasi ini dirancang untuk membantu proses pengelolaan jadwal bus dan pemesanan tiket.

## Teknologi
- Python
- Object-Oriented Programming (OOP)
- Streamlit
- Unit Testing

## Struktur Proyek
```text
aplikasi-management-transportasi-umum-bus/
├── app.py
├── requirements.txt
├── models/
│   ├── __init__.py
│   ├── jadwal.py
│   ├── kendaraan.py
│   ├── bus_ekonomi.py
│   ├── bus_eksekutif.py
│   ├── pelanggan.py
│   └── pemesanan_tiket.py
├── exceptions/
│   ├── __init__.py
│   └── exceptions.py
└── tests/
    └── test_jadwal.py
```

## Fitur Aplikasi
- Pengelolaan jadwal bus
- Pengelolaan data kendaraan
- Pengelolaan pelanggan
- Pemesanan tiket bus
- Pemilihan kursi
- Riwayat pemesanan
